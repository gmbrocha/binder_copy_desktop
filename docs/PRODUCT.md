# Product scope

BinderCopy is a private page/collection workspace built on a shared card catalog. Preserve current Build / Cards / Library workflows, current transparent branding, safe areas, concise copy and typography. Read the preserved handoff's PRODUCT_AND_UX.md and ACCEPTANCE_CHECKLIST.md for full parity.

This client owns native interactions, accessible layout, token storage, recovery drafts, media/file permissions and share/save flows. Server permissions and spending cannot be overridden locally.

## Explicit exclusions until separately accepted

No unrelated redesign, Windows first release, full offline sync, marketplace checkout, unbounded AI, or public sharing. Exact subscription price and allowance remain undecided. TestFlight beta delivery is the active target, not a claim of public App Store approval.
