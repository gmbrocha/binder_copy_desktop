## Findings fixed

- A Library snapshot could reopen older content after an in-flight save. Both clients now settle meaningful saves before listing/navigation and resolve the current page to its latest acknowledged revision. Regression tests cover delayed completion, newer remote revisions and failed-save preservation.
- Several button handlers relied only on React state to exclude duplicate actions. Both clients now lock synchronously with a ref while auth, Library, card-detail and search actions run.
- Failed Library loading had no retry outside its edit dialog. Reload pages is available in that error state.
- The vision worker's late exit could reject replacement-worker requests. Worker ownership is checked, pending work is bounded to 32 requests, and shutdown rejects outstanding work immediately. Two process-fixture tests reproduce these boundaries.
- One domain manifest hash depended on Windows CRLF bytes and disagreed with Git checkout. Exports now canonicalize LF; client boundary checks verify every pinned hash. DTO version remains 0.1.0; no wire-format change.
- Mac CLI 20.0.0 brought fast-xml-parser 4.5.7. CLI/platform tooling was moved together to 20.2.0, which resolves 5.11.2. Native runtime versions remain unchanged.
- Empty/stale scaffold documentation and mixed Windows-1252/UTF-8 text were corrected. Docs validation now checks every tracked Markdown file for nonempty valid UTF-8. Architecture, module guides, auth/release/parity status and the shared controls/demo guide reflect actual implementation.
