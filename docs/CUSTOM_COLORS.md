# Free page colors

The five presets are now muted mid-tone Mist, Ocean, Peach, Sage and Lilac. Their saved IDs remain forge/ocean/ember/forest/plum, so existing pages still open. Native legacy scenery PNGs were re-rendered from the same shared vector helper.

On iPhone, open Preview, choose Color and tap Custom. On Mac, use Color > Custom in the builder's appearance rail. Pick a swatch or enter any six-digit #RRGGBB value, then Apply. Custom solid colors are available to every signed-in account, including Free, with no provider call or credit debit. Choosing a preset or Match my cards clears the override. Undo restores the prior choice. Generated art remains a separate gated feature; a retained custom solid color does not recolor an existing generated image.

The optional customColor field is validated and canonicalized by shared contract 0.2.3. Preview, Library thumbnails and PNG export use the same resolver. Title and logo independently select dark ink or cream from WCAG relative-luminance contrast. Solid colors resolve locally. Generated and legacy scenery are sampled in their actual title/footer regions by the free authenticated API; it makes no model call. The better lower-quartile contrast wins. The artwork appears with its measured overlays after image load; unavailable artwork falls back to the selected solid color with matching ink. PNG export uses the same measurement and stretch geometry. High-frequency mixed artwork can still contain locally low-contrast pixels; this is best-of-two selection, not a claim that every pixel meets a contrast threshold. Changes use ordinary page autosave and revision handling. The iPhone preview handles keyboard insets and Apply taps while entering hex values.

Verification covers free-account HTTP save/reopen and exact PNG pixels, malformed/injected color rejection, no generation dispatch/spend, legacy compatibility and native session Undo/persistence. Release availability and actual native UI evidence belong in CURRENT_STATE.md; this document alone is not proof of an installed build.
