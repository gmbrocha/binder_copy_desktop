# Free page colors

The five presets are now pale Mist, Ocean, Peach, Sage and Lilac. Their saved IDs remain forge/ocean/ember/forest/plum, so existing pages still open. Native legacy scenery PNGs were re-rendered from the same shared vector helper.

On iPhone, open Preview, choose Color and tap Custom. On Mac, use Color > Custom in the builder's appearance rail. Pick a swatch or enter any six-digit #RRGGBB value, then Apply. Custom solid colors are available to every signed-in account, including Free, with no provider call or credit debit. Choosing a preset or Match my cards clears the override. Undo restores the prior choice. Generated art remains a separate gated feature; a retained custom solid color does not recolor an existing generated image.

The optional customColor field is validated and canonicalized by shared contract 0.2.2. Preview, Library thumbnails and PNG export use the same resolver. Titles select black/white for contrast on custom colors; light pages use the existing dark wordmark. Changes use ordinary page autosave and revision handling. The iPhone preview handles keyboard insets and Apply taps while entering hex values.

Verification covers free-account HTTP save/reopen and exact PNG pixels, malformed/injected color rejection, no generation dispatch/spend, legacy compatibility and native session Undo/persistence. Release availability and actual native UI evidence belong in CURRENT_STATE.md; this document alone is not proof of an installed build.
